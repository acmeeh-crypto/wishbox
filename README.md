# 소원 보관함 (시즌2)

두 사람(R & D)의 소원을 함께 등록하고 관리할 수 있는 **깔끔하고 가독성 높은 Pretendard 폰트 기반의 파스텔 일러스트 카드 스타일** 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **소원 작성자 R과 D & 사진 얼굴 아바타**
   - 작성자 'R'(Robyn)과 'D'(Donghoon)의 실제 사진에서 추출한 고화질 원형 얼굴 아바타(`avatar_r.png`, `avatar_d.png`) 적용
   - 소원 작성 버튼, 소원 카드 배지, 필터 탭, 통계 바에 두 사람의 얼굴 아바타 표시
   - 프로필 설정에서 닉네임 변경 및 사진 ↔ 동물/오브젝트 이모지 간 자유로운 전환 지원

2. **소원 등록 및 등록 날짜 자유 설정**
   - **'소원 등록'** 폼에서 원하는 **등록 날짜 및 시간**을 달력 선택기로 자유롭게 지정 가능
   - 설정한 등록일로부터 **30일 뒤 소멸 날짜가 자동 계산**되어 실시간으로 표시
   - 소원 내용을 적지 않고도 즉시 등록 가능하며, 등록 후 언제든지 카드에서 직접 작성 및 수정 가능

3. **소원 3단계 생명주기 및 30일 자동 카운트다운**
   - **등록 (진행 중 ⏳)**: 설정된 등록일로부터 **30일 자동 카운트다운** 진행 (실시간 D-Day 및 남은 일/시간/분, 진행 게이지 바 표시)
   - **완료 (이룬 소원 🎉)**: 소원이 이루어졌을 때 `[✔️ 소원 이루기(완료)]` 버튼으로 즉시 완료 상태 전환
   - **소멸 (기한 만료 💨)**: 30일이 경과하면 **자동으로 '소멸' 단계**로 전환 (언제든 `[✨ 30일 재등록하기]`로 다시 시작 가능)

4. **소원 현황 통계판 (실시간 집계)**
   - 현재 진행 중인 소원 수 큰 숫자 하이라이트
   - 전체 / 진행 중 / 완료 / 소멸 개수 실시간 집계
   - R과 D 각각의 `진행 X · 완료 Y` 현황 바 제공

5. **단독 브라우저 실행 & Supabase 실시간 동기화 지원**
   - 브라우저에서 `index.html`을 더블 클릭하면 설치 없이 즉시 로컬 저장소(localStorage)로 동작
   - 우측 상단 `[☁️ 동기화 설정]`에서 무료 Supabase의 Project URL과 Anon Key를 입력하면 스마트폰과 PC 간 실시간 동기화 가능
